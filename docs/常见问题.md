# 常见问题

## 使用

**Q：口令码丢了怎么办？**
A：口令码只在前端展示，后端不提供反查。请从「历史记录」里找回；历史记录清空后无法恢复。

**Q：对方没有安装这个软件能取件吗？**
A：不能。取件需要使用同一个客户端。如果只是想要一个普通文件，那就直接发文件。

**Q：传大文件会不会很慢？**
A：取决于平台上传速度和分片数量。程序会先做本地加密与装箱，再逐片上传，可在界面看到进度。

**Q：为什么载体图片看起来就是一张普通图片？**
A：数据附加在图片字节流尾部，不改像素。任何看图工具都能正常打开，只是文件比原图大一些。

## 故障

**Q：点最小化按钮没反应，画面还闪一下？**
A：这是 FluentUI 无边框窗口缺少 `WS_MINIMIZEBOX` 导致的，0.2.0 已修复。如果你用的是更早的构建，请升级。

**Q：启动报 `0xC0000135`？**
A：缺少运行库（`libsodium.dll` 或 VC143 CRT）。请使用安装版，或确保便携目录里这几个 DLL 齐全。

**Q：启动后立刻退出、无任何提示？**
A：先看日志：`%LOCALAPPDATA%\Cangjian\藏笺\cache\pipeline.log`。如果是自己编译的 Release，先排除「构建被中断留下的坏产物」（删 `build\Release` 全量重建）。

**Q：提示口令码无效？**
A：确认 5 位字母没有抄错；口令码区分名称不区分大小写（输入会自动转大写）。也可能是后端尚未部署对应接口。

**Q：提取时提示载体损坏？**
A：平台对图片做了重新编码，尾部数据被破坏。换用固定规格承载图的平台（如哔哩哔哩）重试。

**Q：安装包被 SmartScreen 拦截？**
A：项目暂未做代码签名，属预期行为。可选择「更多信息 → 仍要运行」，或校验 `SHA256SUMS.txt` 后运行。

## 开发

**Q：为什么 `CMakeLists.txt` 里有 `E:/pz/...` 这种路径？**
A：作者本机的默认依赖位置。用 `-DFLUENTUI_ROOT=...` 等参数覆盖即可，见 [构建指南](构建指南.md)。

**Q：能不能在 Linux/macOS 上编译？**
A：当前实现依赖 Windows API（DPAPI、无边框窗口处理、Windows 资源），未做跨平台适配。
